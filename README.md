# Scientific Talk Slides

用于科研汇报、组会和答辩 PPT 的 Codex 技能。

覆盖研究动机与叙事、文献图与引用、公式及比较条件核对、逐页讲稿备注、页码与隐藏备份页，以及原文件保护。

## 安装

将本仓库文件放入个人技能目录 `~/.codex/skills/scientific-talk-slides/`，确保 `SKILL.md` 位于该目录下。

Windows 对应目录为 `%USERPROFILE%\.codex\skills\scientific-talk-slides\`。

## 使用

在 Codex 中调用 `$scientific-talk-slides`，并提供论文、已有 PPT 或需要修改的页面。例如：

> 使用 scientific-talk-slides，根据这篇论文组织一份组会报告，补充研究动机，并写好逐页备注。备注不要标注时长。

实际创建或修改 PPTX、Google Slides 时，需要搭配当前环境中可用的 `presentations` 制作技能。本仓库包含科研内容与讲述规范，不包含该制作技能及其运行时。
